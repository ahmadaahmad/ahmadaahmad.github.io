Azure data engineering

Azure incremental-load pipeline

A daily pipeline that processes new and changed records without reloading the entire dataset.

The problem

Most records don’t change

Daily extracts can contain many of the same records. A full reload would process the entire dataset each time, even when only a small share has changed.

Load only new or changed records

Merge just the changes

I built a pipeline with Azure Data Factory, Data Lake Storage, and Azure SQL. It stages each batch and merges new or updated records into the target table without rebuilding it.

The daily run

How the pipeline works

  1. 01
    The pipeline picks up the daily extract.

    Azure Data Factory reads the daily CSV and writes the changed rows to Data Lake Storage as Parquet files.

  2. 02
    It stages the batch in Azure SQL.

    It loads those files into a staging table before updating the target table.

  3. 03
    It merges new and updated records into the target table.

    The merge inserts new records and updates matching ones without reloading the whole table.

  4. 04
    It saves the latest timestamp from the batch so the next run can find records that changed after that point.

    During extraction, the pipeline records the latest modification date as the starting point for the next extract.
