Azure data engineering

Azure incremental-load pipeline

A daily pipeline that processes new and changed records without reloading the entire dataset.

The problem

Most records don’t change

Daily extracts can contain many of the same records. A full reload would process the entire dataset each time, even when only a small share has changed.

The approach

Merge just the changes

I built a pipeline with Azure Data Factory, Data Lake Storage, and Azure SQL. It stages each batch and merges new or updated records into the target table without rebuilding it.

The daily run

How the pipeline works

  1. 01The pipeline picks up the daily extract.
  2. 02It stages the batch in Azure SQL.
  3. 03It merges new and updated records into the target table.
  4. 04It saves the latest timestamp from the batch so the next run can find records that changed after that point.
