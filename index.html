Technical note

Secure embedding with .NET

In a secure app, a signed-in user should see only their assigned regions. The .NET backend requests a Power BI embed token with the user identity and role. Power BI applies the model’s row-level security when it loads the report.

Architecture note only. The public demo does not enforce this access model.
